## Overview

This is the leading INFRA sprint — nothing else in the MK-VI migration starts until it is green. It proves, against real Bun + real Postgres, that an exact, pinned set of Mastra / AI-SDK / Zod versions actually boots one agent, one tool, one workflow, one MCP transport, and one OTel trace (the compatibility lock per `11-runtime-contracts.md`), and it stands up the versioned Fleet Role Manifest that every later mission resolves its model roles through — failing closed when a declared capability is absent. The `holo` operator CLI is bootstrapped here as the surface every downstream sprint's human-testing gate is exercised through.

---

## Human Test Deliverable

An operator can prove the pinned runtime combination is real by running one command that boots the whole locked stack against a real Postgres and reports a green five-cell smoke matrix — and that the Fleet Role Manifest resolves live roles and fails closed on a missing capability.

**Test Steps:**
1. Run `holo compat:spike` on the pinned lockfile against a running Postgres — exits 0, prints a green 5-cell matrix.
2. Run `holo compat:record` — names exact Bun, @mastra/core, @mastra/pg, @mastra/mcp, AI-SDK, Zod versions with release dates.
3. Run `holo compat:spike --print-trace` — emits one OTel trace with agent, tool, and workflow child spans.
4. Stop Postgres and re-run `holo compat:spike` — fails closed naming the unreachable store (proves no mock).
5. Run `holo manifest:validate` against the live fleet — resolves divergent, convergent, and embed roles to :4545 endpoints.
6. Remove one required role from the manifest and re-run `holo manifest:validate` — exits non-zero naming the missing capability.
