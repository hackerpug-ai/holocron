# A dropped connection is marked the same way a reload is

Mid-answer, drop the network at the transport layer rather than reloading the page, and leave it down for sixty seconds. The turn must reach the same explicit interrupted state within a bounded window - not remain in a streaming state with a blinking cursor forever, and not silently stop at the last received word looking like a short but complete answer. Restore the network and confirm the state does not spontaneously flip back to streaming.
