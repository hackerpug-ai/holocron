# A very large selection travels without losing its source

Select roughly 5,000 characters spanning three headings, a figure and a code block, then ask about it. The passage that arrives in Chats may be truncated, but the truncation must be visible as such and the source document must still be identified by title and id in the dispatched payload. A selection that arrives with the quote intact but the source lost is the failure mode named in the journey, because the answer then addresses the wrong thing with no way to check.
