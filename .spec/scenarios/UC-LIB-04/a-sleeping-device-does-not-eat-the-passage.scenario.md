# A sleeping device does not eat the passage

Stop the device platform, select a passage, and activate the control. Chats must open with the full quote and the source title intact, and the failure must be named as an archive-host problem when the follow-up is sent. The operator's quoted passage must remain in the input or in the transcript afterwards, recoverable without going back to the document. Returning to the document must still restore the scroll position.
