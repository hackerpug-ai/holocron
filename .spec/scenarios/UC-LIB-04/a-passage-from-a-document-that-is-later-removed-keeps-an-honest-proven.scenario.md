# A passage from a document that is later removed keeps an honest provenance

Ask about a passage, then delete the source document on the device before sending the follow-up. The conversation must still name the source it came from and must state in real copy that the source is no longer available, rather than silently dropping the attribution or presenting the quote as unsourced. Also confirm that a passage carried from a document does not become quotable into a conversation whose id was substituted by hand.
