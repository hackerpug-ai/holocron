# Filtering while the device is asleep names the device

Stop the device platform, then apply a chip. The surface must name the archive host as unreachable in real copy rather than rendering zero results, and the chips must remain visibly applied so the operator knows what state he is in when he retries. Retry after waking the platform must reproduce the filtered set exactly, without resetting the chips.
