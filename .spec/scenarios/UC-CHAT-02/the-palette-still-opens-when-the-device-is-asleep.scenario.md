# The palette still opens when the device is asleep

Stop the device platform, then press the keystroke from the Library. The palette must open and list its six commands with descriptions, because the command list belongs to the client. Submitting a command must then fail with the archive host named as the cause, and the operator's typed argument must remain recoverable in the input rather than being cleared by a failed dispatch.
