# The first load of a long document paints text before anything else

From a cold profile with no cached fonts and a cold worker, open the 4,200-word document and record the paint sequence. Text must be the first content painted. A full-column skeleton, a font-swap flash that hides all text, or a layout that reflows by more than a small amount once figures load all fail here - the operator's reading column is supposed to be the same calm surface the stranger gets.
