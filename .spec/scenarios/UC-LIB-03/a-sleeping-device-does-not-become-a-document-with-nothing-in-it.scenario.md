# A sleeping device does not become a document with nothing in it

Stop the device platform and open a document that was already listed in a stale Library view. The surface must name the archive host as unreachable in real copy rather than rendering an empty reading column or a title with no body. Retry after waking must render the full 4,200-word document without navigating away.
