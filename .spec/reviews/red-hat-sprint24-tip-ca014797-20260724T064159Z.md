## GATE-FIX-007b — is `document-share-url` genuine product behavior or evidence theatre?

**Verdict: LEGITIMATE TESTABILITY SEAM. Not evidence theatre.**

### The testability problem GATE-FIX-007b solves

iOS `UIActivityViewController` (invoked by RN `Share.share`) exposes only the URL **host** to accessibility/Maestro (e.g. `"127.0.0.1"`), not the path. Without a seam, no Maestro oracle could prove the URL path is `/article/<token>` rather than, say, a stale `.convex.site` URL. The commit message documents this honestly: *"iOS share-sheet a11y only exposes the host (127.0.0.1), not /article/."*

### Why this is not theatre

| Property | Evidence |
|----------|----------|
| **Seam value IS the user-visible value** | `app/document/[id].tsx:471-490`: `const shareUrl = await getShareUrl(); … setLastShareUrl(shareUrl); … Share.share({ url: shareUrl, message: shareUrl, … })`. The exact string mounted in `document-share-url` is the exact string handed to `Share.share`. If `Share.share` would receive `/article/`, the seam shows `/article/`; if it would receive `.convex.site`, the seam shows `.convex.site`. |
| **URL is genuinely user-visible** | `Share.share` is the real platform share invocation. The URL appears in the user's chosen share destination (Messages, AirDrop, clipboard, etc.). The seam does not fabricate a URL that the user never sees — it mirrors the URL the user does see, just in a queryable location. |
| **Oracle observes both directions** | `share-url-mastra.yml:101-108`: positive `assertVisible .*(/article/).*` AND negative `assertNotVisible .*\.convex\.site.*`, `.*\.convex\.cloud.*`. A Convex-host regression in `buildArticleShareUrl` would fail both checks. The negative assertions are also stricter than the seam alone: any element in the hierarchy exposing a Convex host would fail the gate. |
| **Mutator/seed path is real** | Seed grants stable tokens (`seed-e2e.ts:217`); gate-path `getShareUrl` early-returns via `buildArticleShareUrl(document.shareToken)` (`[id].tsx:437-438`). The fallback in `:449-460` is a durability path for production docs without seeded tokens, not a gate-only stub. |
| **Not a hardcoded oracle string** | The seam renders `{lastShareUrl}` (runtime state), not a literal `/article/`. If the runtime URL were wrong, the seam would show the wrong value and the oracle would fail. |

### Residual concern (LOW-1, non-blocking)

The seam uses `style={{ position: 'absolute', width: 1, height: 1, opacity: 0.02, left: 0, bottom: 0 }}` plus `accessibilityLabel={lastShareUrl}`. Visually it is invisible (1×1, 2% opacity) but its `accessibilityLabel` could be read by VoiceOver post-share. The value is the same URL the user just shared, so a VoiceOver read is benign — but the cleaner pattern is `accessible={false}` (or `importantForAccessibility="no"`). Not a regression on any existing surface (the node did not exist before `ca014797`), not blocking.

### Contrast with actual theatre patterns

| Theatre pattern | This seam |
|----------------|-----------|
| Hidden element with hardcoded expected string | ❌ renders runtime state `{lastShareUrl}` |
| Oracle observes a value the user never sees | ❌ observes the exact value passed to `Share.share` |
| Stubbed handler that returns the expected value without doing the work | ❌ `getShareUrl` runs the real publish/Zero-read path; `Share.share` is invoked with the real URL |
| Test-only branch that fires under test conditions | ❌ seam is unconditional post-share; same code path in production |
