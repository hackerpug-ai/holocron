- [ ] **H1 — Escape dual-path bypasses degraded never-cloud** | Severity: **HIGH**

      Fix: Rewrite human steps to the actual operator surface (`infer:call` / suite) **or** implement mission and re-run gate honestly.

- [ ] **H3 — Local-first is seam-only, not structural** | Severity: **HIGH**  
      Agents: mastra-reviewer, code-reviewer  
      Evidence: `resolveModel` production callers = CLI + `DegradedModeController` only. `createFleetChatModel` is defined and **never called** outside `resolve-model.ts:221-236`. `compat/cells/agent.ts:74-84` hardcodes `createOpenAICompatible({ baseURL: FLEET_URL })` with static model `compat-spike`. `verify:no-provider-refs` only bans `claudeFlash|Pro|Ultra`, not general provider SDKs.
