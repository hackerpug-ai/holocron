## Findings

### HIGH-01 — Credentialed PITR preflight executes an untrusted Bun candidate

**Confidence:** High
**Category:** secret handling / live-gate integrity / test reality
**Location:** `services/platform/tests/integration/sprint28-s28r3-qa31-ambient-prefix-execution.test.ts:310-318,349-357`

`bunBin()` selects the first executable path, explicitly including `/Users/inference1/.bun/bin/bun` and `/opt/homebrew/bin/bun`; it performs no owner, mode, symlink, or root-trust validation. `queryPitrWindow()` then passes `envForConfig(...)`—which contains the ignored live R2 credentials—to that binary for `restore:window`. The error text even calls such a binary “trusted” without proving it.

This reopens the exact credential-exposure/trust-boundary failure class that the real fire-drill consumer carefully closes before accepting credentials. It also weakens the claim that the PITR timestamp came from a trusted live source: a substituted executable can fabricate output and receive the credential environment. Require the same absolute, root-owned validation class used by the credentialed consumer before building the environment or spawning Bun; otherwise make the positive gate an explicit dependency failure with no credentialed process launched.

### MEDIUM-01 — QA31 is checkout-specific and can source credentials from another checkout

**Confidence:** High
**Category:** portability / test isolation
**Location:** `services/platform/tests/integration/sprint28-s28r3-qa31-ambient-prefix-execution.test.ts:28-30,115-124,310-318`

The test embeds `/Users/inference1/Projects/holocron` in `PRIMARY_SECRET_FILE`, candidate secret paths, and the Bun candidate list. Although repository-relative candidates are tried first, a clone/worktree without its own secret configuration can silently use a different checkout's ignored `secrets.yaml`. That defeats checkout-local credential gating and makes portability dependent on one developer's filesystem layout. Accept only an explicit `HOLO_QA31_SECRETS_PATH` or a repository-relative ignored file; remove user-home absolute fallback paths.

### LOW-01 — QA31 introduces trailing whitespace in the copied QA30 source review
